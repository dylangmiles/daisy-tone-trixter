# Tone Trixter — Daisy Seed3

Firmware for the Daisy Seed3 (STM32H750) build of the Tone Trixter, a guitar pedal that makes a
piezo pickup sound like a studio microphone in real time.

A platform variant of the [RP2350 build](https://github.com/dylangmiles/pico-tone-trixter), not a
replacement — the analogue front end is shared between them.

**Status:** scaffold. No firmware yet.

See `CLAUDE.md` for hardware notes, toolchain state and build/flash instructions.
