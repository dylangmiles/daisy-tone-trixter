# Tone Trixter — songs (SONG MODE)
# =========================================================================
# Flow-style YAML, same shape as presets.txt: "name:" starts a song, "---"
# between songs is optional, # comments, no significant indentation.
#
#   name:      shown on screen in large type — up to 14 characters fit
#   type:      song (default) — a preset + optional backing track
#              looping        — a looper session (⚠ firmware pending: until the
#                               looper lands this loads as a plain preset song)
#   preset:    a preset name from presets.txt; omit to keep whatever is loaded
#   backing:   a file in /tonetrix/backing (with or without .wav), or none
#   bpm:       optional. looping: locks the tempo (click / count-in, first pass
#              snaps to whole bars); absent = free, detected from the first pass
#   bars:      optional, looping + bpm: fixes the loop length
#
# On the pedal (Daisy build) — LEFT = bypass switch, RIGHT = tuner switch:
#   normal:       right HOLD               -> song select
#   song select:  left tap = previous       right tap = next
#                 left hold = back to normal right hold = play this song
#   song play:    right PRESS = start / stop (on the beat; looper: rec/play/overdub)
#                 left LONG hold = back to select
#                 (looper: right hold = undo a layer, left tap = stop, left hold = clear)
#   encoder turn = previous / next song, in either state
# Picking a song loads its preset and engages the chain; nothing starts until
# the right switch — so arm the song, then start it on the beat.
