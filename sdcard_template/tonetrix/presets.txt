# Tone Trixter — presets
# =========================================================================
# Flow-style YAML. One preset per block; "---" (or the next "name:") starts a
# new one. Any key you omit inherits the firmware's built-in "default" preset,
# so a preset can be as short as a name + the few things you want to change.
#
#   name:       preset name (shown on screen + selected by config boot_preset)
#   ir:         WAV file in /tonetrix/ir/  (also matches a built-in IR name:
#               "tanglewood" / "garrison"). Use  ir: none  for a dry preset —
#               that turns the whole convolution pipeline OFF. Omitting ir:
#               inherits the default's (which is none).
#   in.on  eq.on  comp.on  out.on   stage enables (1/0, on/off)
#   in.level:   pre-comp input trim, 0.0..8.0 (max raised from 2.0 on 2026-07-24 —
#               with pga at 0 the makeup for the analog gain now lives here)
#   eq.lo:      [freq_Hz, gain_dB]           low shelf
#   eq.mid:     [freq_Hz, gain_dB, Q]        mid peak
#   eq.hi:      [freq_Hz, gain_dB]           high shelf
#   comp:       [thresh_dB, ratio, attack_ms, release_ms, makeup_dB]
#   out.level:  final output level, ~0.0..1.0
#   ir.dry:     0.0..1.0 -- blend a HIGH-PASSED slice of the dry piezo (HP ~2.5 kHz) back onto the
#               wet IR. The body IR kills the piezo quack AND the pick-on-string CLACK with it; a
#               little dry returns the pick attack without the nasal quack. 0 = pure IR (default).
#               ⚠ DAISY-ONLY KEY (Pico parser ignores it). Only audible with an IR loaded. Dial it
#               live on the "IR dry" menu row or `irdry <0..1>` over UART, then write the number here.
#   pga:        ES8388 input PGA gain in dB (0..24, 3 dB steps), set when this preset
#               loads. Passive K&K ~12; active Garrison ~6 (its preamp is hot — +12 clips
#               the ADC on hard strums). Omit to inherit the default (12).
#               ⚠ IGNORED on the Daisy build: the Seed3's TAC5242 has no software gain
#               control, and the front-end level is set by the analogue daughter instead.
#   byp.level:  BYPASS make-up gain, 0.0..8.0, applied ONLY when the chain is bypassed.
#               ⚠ DAISY-ONLY KEY (ignored by the RP2350 parser, like bk.level).
#               Exists so the A/B is LEVEL-MATCHED. Bypass is the raw input; an engaged
#               preset is louder, and for these presets the loudness is the COMPRESSOR's
#               make-up, not out.level. A level difference invalidates an ear A/B --
#               louder simply reads as "better" -- so this lifts the DRY path to meet the
#               wet one instead of turning the preset down.
#               ⚠ Omit or 0 = UNITY (not silence).
#               ⚠ LEAVE THE `default` PRESET AT 1.00. Boot loads it, so the boot state
#               stays a true unity passthrough and is the reference for any measurement.
#   bk.level:   backing-track level, 0.0..2.0, applied when this preset loads.
#               ⚠ DAISY-ONLY KEY. The RP2350 build's parser ignores keys it does not know,
#               so this file stays readable by BOTH pedals — one card, one set of presets.
#               ⚠ Omit (or 0) means "leave the current level alone", NOT silence.
#
# This file reproduces the firmware's three built-in presets. Edit freely —
# the pedal reads it on boot; type `sdreload` over UART to re-read without a
# power cycle.
# =========================================================================

# default — dry baseline: no IR, convolution off. Also the inheritance seed: any preset
# below that omits a key gets it from here. Kept NEUTRAL AND SAFE, not tuned — unity
# in.level, light safety limiting only. attack 1 ms matters: at pga 0 nothing limits
# transients before the DAC, so anything inheriting from here needs a fast attack.
name: default
ir: none
in.on: 1
eq.on: 0
comp.on: 1
out.on: 1
in.level: 1.00
eq.lo: [120, 0.0]
eq.mid: [700, 0.0, 1.0]
eq.hi: [3500, 0.0]
comp: [-18, 3.0, 1, 250, 6]
out.level: 0.60
pga: 0
# ⚠ UNITY, deliberately, and do not change it. `default` is what boots, so the pedal always
# comes up as a true passthrough in bypass -- which makes the boot state the reference for
# any front-end or SNR measurement. Every other preset may lift the dry path; this one must not.
byp.level: 1.00
bk.level: 1.00

---

# tanglewood-slide — passive K&K via the JFET daughter, pga 0. Dialed 2026-07-24: over a full
# slide passage GR runs -6..-14 dB and never hits 0, comp in -5..-17 dBFS comes out -7..-13,
# zero ADC and DAC clips. NO PAD NEEDED — the K&K's worst case (very hard bridge tap) measures
# 0.0 dBFS at the ADC with zero clips. Its hiss is higher than the garrison preset's, and that
# is the IR (flat, passes broadband noise), not the front end — no digital gain can fix it.
name: tanglewood-slide
ir: tanglewood.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [150, 3.0]
eq.mid: [800, -3.0, 1.0]
eq.hi: [1500, -2.0]
comp: [-28, 4.0, 10, 300, 16]
out.level: 0.45
ir.dry: 0.15
pga: 0
# ⚠ OUTPUT LEVELLED 2026-09-09. All three voiced presets now share in.level 0.75, comp make-up 16 dB
# and out.level 0.45, so they are MUTUALLY MATCHED -- switching preset no longer changes loudness.
# ⚠ byp.level 1.6 is EAR-DERIVED at playing level, 2026-09-10 -- it is NOT the static figure.
# Static chain gain is -2.5 + 16 - 6.9 = +6.6 dB, i.e. 2.12x, and 2.1 did sound slightly loud in
# bypass. 1.6 is +4.1 dB.
#
# ⚠ The 2.5 dB gap between them IS the compressor: below the -28 dB threshold the chain runs at the
# full static gain, but at playing level gain reduction pulls it back, so the make-up needed to match
# bypass is correspondingly less. That difference is a rough read of the average GR being applied --
# about 2.5 dB at this builder's playing level on this guitar.
# ⚠ 0.45 is NOT arithmetic unity -- unity would be out.level 0.21 (-13.5 dB). It is the builder's ear
# setting, and with a compressor in circuit "unity" is level-dependent anyway: below the -28 dB
# threshold the chain runs at +6.6 dB, above it gain reduction pulls it back. Trim by ear at PLAYING
# level; if you do move it, move byp.level with it or the A/B stops being honest.
byp.level: 1.6
# ⚠ Bed at 1.00 now that the presets are levelled -- it no longer has to duck a hot guitar.
bk.level: 1.00

# slg110s — Yamaha Silent Guitar SLG110S (steel string, 2009–2014 generation): under-saddle piezo
# into the guitar's OWN active preamp, with onboard reverb/chorus, a tone knob and a headphone out.
# ⚠ NOT the SRT-modelling SLG200 (that would want its body modelling switched OFF; no preset for it
# yet). The 110S has no body modelling to switch off, but it has EFFECTS: ⚠ set the SLG's reverb/chorus to OFF and its TONE to centre
# before judging this, or the IR is convolving a wet, pre-shaped signal and nothing attributes.
#
# No soundbox → no transfer function to capture → borrow the GARRISON IR (captured through an active
# preamp, like this source; an IR embeds its source pickup as well as the target body, and the
# tanglewood IR came through a passive K&K). The 110S's piezo sits brighter and quackier than the
# Garrison's: a cut around 1.2 kHz and a touch more low shelf to start.
# ⚠ ALL EAR VALUES, UNTUNED. Play it against the Garrison; move eq.mid first (frequency, then depth).
#
# Level: the SLG's output is active and can run hot. Start with the guitar's volume at 3/4 (the same
# reference position the garrison preset was dialled at) and watch `clips` on the stats screen — if
# it counts on hard strums, back the guitar's volume off before touching in.level.
name: slg110s
ir: garrison.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
# ⚠ TUNED BY EAR 2026-09-18 over the console (dump below), guitar volume at 1/3, zero ADC clips in
# normal play. The three moves that brought the bite back, in the order they mattered:
#   comp.attack 1 → 20 ms   the 1 ms attack (a K&K bridge-tap safety) was eating the pick transient
#   eq.mid 1200 → 800 Hz, −3.5 → −2 dB   the quack cut had been sitting on the bite, not the honk
#   eq.hi −2 → +2 dB at 3.5 kHz   the garrison IR is dark; the SLG wants the shelf up, not down
eq.lo: [120, 2.5]
eq.mid: [800, -2.0, 1.2]
eq.hi: [3500, 2.0]
comp: [-28, 4.0, 20, 250, 16]
out.level: 0.45
pga: 0
# ⚠ byp.level 1.0 (UNITY), NOT the 1.6 the other presets use -- bypass was much louder than engaged
# at 1.6 (2026-09-18). The SLG's active output runs hotter than the K&K, so the engaged path sits deeper
# into the compressor (−28 dB threshold, 4:1) and needs less dry-side make-up to match. Trim by ear at
# playing level from here; if bypass is still louder, go below 1.0 (0.8 ≈ −2 dB) rather than raising
# out.level, so the preset stays level-matched with the others when switching.
byp.level: 1.0
bk.level: 1.00

# walden — Walden D2040 (dreadnought, solid cedar top, rosewood back/sides) with a K&K Pure Mini
# fitted 2026-09-21. Same pickup as the Tanglewood, so it BORROWS THE TANGLEWOOD IR until a Walden IR
# is captured; this preset exists so the EQ and comp can be voiced for THIS guitar without touching
# tanglewood-slide. ⚠ EAR-GUESSED, UNPLAYED — starting points from what the two guitars are:
#   - a dreadnought has more low end and a bigger box resonance than the Tanglewood; the K&K hears
#     that, so the low shelf drops to +1 and the mid cut moves DOWN to ~600 Hz (dreadnought boom sits
#     lower than the smaller body's honk) and goes slightly deeper.
#   - cedar top = warmer, softer attack, less top-end than spruce; the high shelf is left FLAT rather
#     than cut, so the cedar isn't dulled further.
#   - flatpicking / strumming rather than slide: a slower comp attack (10 ms) keeps the pick transient,
#     a lower ratio (3:1) and a longer release (400 ms) breathe with strummed chords instead of pumping.
#     Threshold stays at -28 so the make-up and out.level line up with the other presets (level-matched).
# Tune order: play it against tanglewood-slide on the same phrase; move eq.mid_freq first (500..800),
# then eq.mid_gain, then comp.attack. `dump` when it lands and write the numbers here.
# Same K&K → no pad, guitar at full volume (the K&K has no volume), watch `clips` on hard strums.
name: walden
ir: tanglewood.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [120, 1.0]
eq.mid: [600, -3.5, 1.0]
eq.hi: [3500, 0.0]
comp: [-28, 3.0, 10, 400, 16]
out.level: 0.45
pga: 0
# Same levelling as the others -- see tanglewood-slide. 1.6 was ear-derived on the Tanglewood with the
# same pickup, so it is the right starting point; trim on the BYP level menu row if the A/B is off.
byp.level: 1.6
bk.level: 1.00
