# Tone Trixter — presets
# =========================================================================
# Flow-style YAML. One preset per block; "---" (or the next "name:") starts a
# new one. Any key you omit inherits the firmware's built-in "default" preset,
# so a preset can be as short as a name + the few things you want to change.
#
#   name:       preset name (shown on screen + selected by config boot_preset)
#   ir:         WAV file in /tonetrix/ir/  (also matches a built-in IR name:
#               "tanglewood" / "garrison"). Use  ir: none  for a dry preset —
#               that turns the whole convolution pipeline OFF. Omitting ir:
#               inherits the default's (which is none).
#   in.on  eq.on  comp.on  out.on   stage enables (1/0, on/off)
#   in.level:   pre-comp input trim, 0.0..8.0 (max raised from 2.0 on 2026-07-24 —
#               with pga at 0 the makeup for the analog gain now lives here)
#   eq.lo:      [freq_Hz, gain_dB]           low shelf
#   eq.mid:     [freq_Hz, gain_dB, Q]        mid peak
#   eq.hi:      [freq_Hz, gain_dB]           high shelf
#   comp:       [thresh_dB, ratio, attack_ms, release_ms, makeup_dB]
#   out.level:  final output level, ~0.0..1.0
#   ir.dry:     0.0..1.0 -- blend a HIGH-PASSED slice of the dry piezo (HP ~2.5 kHz) back onto the
#               wet IR. The body IR kills the piezo quack AND the pick-on-string CLACK with it; a
#               little dry returns the pick attack without the nasal quack. 0 = pure IR (default).
#               ⚠ DAISY-ONLY KEY (Pico parser ignores it). Only audible with an IR loaded. Dial it
#               live on the "IR dry" menu row or `irdry <0..1>` over UART, then write the number here.
#   pga:        ES8388 input PGA gain in dB (0..24, 3 dB steps), set when this preset
#               loads. Passive K&K ~12; active Garrison ~6 (its preamp is hot — +12 clips
#               the ADC on hard strums). Omit to inherit the default (12).
#               ⚠ IGNORED on the Daisy build: the Seed3's TAC5242 has no software gain
#               control, and the front-end level is set by the analogue daughter instead.
#   byp.level:  BYPASS make-up gain, 0.0..8.0, applied ONLY when the chain is bypassed.
#               ⚠ DAISY-ONLY KEY (ignored by the RP2350 parser, like bk.level).
#               Exists so the A/B is LEVEL-MATCHED. Bypass is the raw input; an engaged
#               preset is louder, and for these presets the loudness is the COMPRESSOR's
#               make-up, not out.level. A level difference invalidates an ear A/B --
#               louder simply reads as "better" -- so this lifts the DRY path to meet the
#               wet one instead of turning the preset down.
#               ⚠ Omit or 0 = UNITY (not silence).
#               ⚠ LEAVE THE `default` PRESET AT 1.00. Boot loads it, so the boot state
#               stays a true unity passthrough and is the reference for any measurement.
#   bk.level:   backing-track level, 0.0..2.0, applied when this preset loads.
#               ⚠ DAISY-ONLY KEY. The RP2350 build's parser ignores keys it does not know,
#               so this file stays readable by BOTH pedals — one card, one set of presets.
#               ⚠ Omit (or 0) means "leave the current level alone", NOT silence.
#
# The firmware's ONLY built-in preset is `default` (a transparent passthrough, the no-card
# fallback); every voiced preset lives here on the card. Edit freely — the pedal reads this on
# boot; type `sdreload` over UART to re-read without a power cycle.
# =========================================================================

# default — "basically bypass": a TRANSPARENT passthrough. No IR, EQ off, comp OFF, in and out at
# unity, so engaging it colours nothing. Also the inheritance seed: any preset below that omits a key
# gets it from here. The comp params stay sane ONLY as that seed — ⚠ attack 1 ms matters: at pga 0
# nothing limits transients before the DAC, so any preset that turns comp ON must inherit a fast attack.
name: default
ir: none
in.on: 1
eq.on: 0
comp.on: 0
out.on: 1
in.level: 1.00
eq.lo: [120, 0.0]
eq.mid: [700, 0.0, 1.0]
eq.hi: [3500, 0.0]
comp: [-18, 3.0, 1, 250, 6]
out.level: 1.00
pga: 0
# ⚠ UNITY, deliberately, and do not change it. `default` is what boots, so the pedal always comes up
# as a true passthrough -- engaged OR bypassed, now that every stage is off/unity -- which makes the
# boot state the reference for any front-end or SNR measurement. Every other preset may lift the dry
# path; this one must not.
byp.level: 1.00
bk.level: 1.00

# tanglewood-slide — the Tanglewood's main preset: passive K&K, pga 0. Dialed 2026-07-24: over a full
# slide passage GR runs -6..-14 dB and never hits 0, comp in -5..-17 dBFS comes out -7..-13, zero ADC
# and DAC clips. NO PAD NEEDED — the K&K's worst case (very hard bridge tap) measures 0.0 dBFS at the
# ADC with zero clips. Its hiss is higher than the garrison preset's, and that is the IR (passes
# broadband noise), not the front end — no digital gain can fix it.
# ⚠ CONSOLIDATED 2026-10-18 to the `_Std` IR + Neve transformer — the former tanglewood-thick recipe,
# which won the A/B. The tanglewood-std / -bld / -thick comparison presets are now removed. Was the
# `_M` IR (tanglewood.wav): the `_Std` IR (+11 dB at 8.5-9.5k vs the `_M`'s +21) drops the slide "fizz"
# the `_M` correction rode on, and the transformer adds body/warmth without pushing the IR or the EQ
# (see private/docs/daisy_slide_high_e_brief_2026-10-17.md). EQ + comp are the standard slide voicing.
# ⚠ Card-only now: tanglewood-std.wav is an SD file. The `_M` tanglewood is still the BUILT-IN no-card
# fallback (and carries no transformer), so a card-less boot plays the old IR dry of the xfmr.
# ⚠ EQ RE-VOICED BY MEASUREMENT 2026-10-24: pedal TSout + NT1-A ~20 cm off the soundhole, one take with
# slide (private/docs/debugging/preset_tuning_2026-10-24/). vs the mic the pedal was ~7 dB HEAVY at
# 80-200 Hz and 5-8 dB SHORT everywhere above 2.5 kHz (5.4 dB rms off the mic) -- the old EQ
# (eq.lo [150, 3.0]  eq.mid [800, -3.0, 1.0]  eq.hi [1500, -2.0]) boosted the lows and cut the top, both
# the wrong way. New EQ = cut-preferring 3-band fit, 3.1 dB rms off the mic. Level -2.7 dB pre-comp,
# ~-0.7 after. NOT EQ-able: a narrow -8.6 dB NOTCH at 250 Hz in the March tanglewood-std IR -- needs
# the fresh Tanglewood IR capture (planned once the extra XLR cables arrive).
# ⚠ EAR-CHECK THE HIGH-E SLIDE FIRST: +5 at 3.5k is what the mic says, but the 8-9.5k fizz was this
# preset's old problem -- if it fizzes, eq.hi +5 -> +3 (or eq.hi_freq 3500 -> 2500 at +3). If boxy,
# eq.mid -8 -> -5; if thin, eq.lo -5 -> -3.
name: tanglewood-slide
ir: tanglewood-std.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [185, -5.0]
eq.mid: [500, -8.0, 2.5]
eq.hi: [3500, 5.0]
comp: [-28, 4.0, 10, 300, 16]
out.level: 0.45
ir.dry: 0.15
pga: 0
# ⚠ Neve-style transformer saturation (xfmr, Daisy-only). Sits post-EQ / pre-comp. Adds low-order
# harmonics weighted to the lows/low-mids for "1073" body and warmth -- it thickens, it does NOT remove
# the 8-9k fizz (the `_Std` IR does that). Gain-compensated, so it stays level-matched.
# ⚠ EAR-GUESSED starting point -- tune live over UART (xfmr.drive, xfmr.mix, ...) or on the OLED
# (MAIN -> xfmr), then write the numbers back here.
# xfmr: [drive_dB, tilt_dB, bias, hf_freq_Hz, hf_gain_dB, mix]
#   drive  into the nonlinearity, gain-compensated out (keep <=6: saturation rounds the pick strike,
#          and >~10 dB aliases at 48 kHz -- A/B the muted strike and back off if it softens).
#   tilt   low-shelf pre-emphasis so the LOWS saturate more (the transformer trait); 0 = flat saturation.
#   bias   asymmetry -> even harmonics (class-A feel); 0 = symmetric/odd only.
#   hf_f/hf_g  gentle HF shelf cut = "soft top".
#   mix    wet/dry. ⚠ 0 = OFF. Drop toward 0 to dial the effect back; raise the drive for more grit.
xfmr.on: 1
xfmr: [6, 4, 0.1, 10000, -1.5, 1.0]
# ⚠ OUTPUT LEVELLED 2026-09-09. The voiced presets share in.level 0.75, comp make-up 16 dB and
# out.level 0.45, so they are MUTUALLY MATCHED -- switching preset no longer changes loudness.
# ⚠ byp.level 1.6 is EAR-DERIVED at playing level, 2026-09-10 -- it is NOT the static figure. (Pre-
# transformer: static chain gain -2.5 + 16 - 6.9 = +6.6 dB, i.e. 2.12x; 2.1 sounded slightly loud in
# bypass, 1.6 is +4.1 dB.) ⚠ The transformer now sits in the chain (gain-compensated, so roughly
# neutral) -- re-trim byp.level on the BYP level menu row at playing level to confirm the match holds.
# ⚠ The 2.5 dB gap IS the compressor: below the -28 dB threshold the chain runs at full static gain,
# but at playing level gain reduction pulls it back, so the make-up to match bypass is less -- a rough
# read of the average GR at this builder's playing level on this guitar.
# ⚠ 0.45 is NOT arithmetic unity -- unity would be out.level 0.21 (-13.5 dB). It is the builder's ear
# setting, and with a compressor in circuit "unity" is level-dependent anyway. Trim by ear at PLAYING
# level; if you do move it, move byp.level with it or the A/B stops being honest.
byp.level: 1.6
# ⚠ Bed at 1.00 now that the presets are levelled -- it no longer has to duck a hot guitar.
bk.level: 1.00

# slg110s — Yamaha Silent Guitar SLG110S (steel string, 2009–2014 generation): under-saddle piezo
# into the guitar's OWN active preamp, with onboard reverb/chorus, a tone knob and a headphone out.
# ⚠ NOT the SRT-modelling SLG200 (that would want its body modelling switched OFF; no preset for it
# yet). The 110S has no body modelling to switch off, but it has EFFECTS: ⚠ set the SLG's reverb/chorus to OFF and its TONE to centre
# before judging this, or the IR is convolving a wet, pre-shaped signal and nothing attributes.
#
# No soundbox → no transfer function to capture → borrow the GARRISON IR (captured through an active
# preamp, like this source; an IR embeds its source pickup as well as the target body, and the
# tanglewood IR came through a passive K&K). The 110S's piezo sits brighter and quackier than the
# Garrison's: a cut around 1.2 kHz and a touch more low shelf to start.
# ⚠ ALL EAR VALUES, UNTUNED. Play it against the Garrison; move eq.mid first (frequency, then depth).
#
# Level: the SLG's output is active and can run hot. Start with the guitar's volume at 3/4 (the same
# reference position the garrison preset was dialled at) and watch `clips` on the stats screen — if
# it counts on hard strums, back the guitar's volume off before touching in.level.
name: slg110s
ir: garrison.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
# ⚠ TUNED BY EAR 2026-09-18 over the console (dump below), guitar volume at 1/3, zero ADC clips in
# normal play. The three moves that brought the bite back, in the order they mattered:
#   comp.attack 1 → 20 ms   the 1 ms attack (a K&K bridge-tap safety) was eating the pick transient
#   eq.mid 1200 → 800 Hz, −3.5 → −2 dB   the quack cut had been sitting on the bite, not the honk
#   eq.hi −2 → +2 dB at 3.5 kHz   the garrison IR is dark; the SLG wants the shelf up, not down
eq.lo: [120, 2.5]
eq.mid: [800, -2.0, 1.2]
eq.hi: [3500, 2.0]
comp: [-28, 4.0, 20, 250, 16]
out.level: 0.45
pga: 0
# ⚠ byp.level 1.0 (UNITY), NOT the 1.6 the other presets use -- bypass was much louder than engaged
# at 1.6 (2026-09-18). The SLG's active output runs hotter than the K&K, so the engaged path sits deeper
# into the compressor (−28 dB threshold, 4:1) and needs less dry-side make-up to match. Trim by ear at
# playing level from here; if bypass is still louder, go below 1.0 (0.8 ≈ −2 dB) rather than raising
# out.level, so the preset stays level-matched with the others when switching.
byp.level: 1.0
bk.level: 1.00
